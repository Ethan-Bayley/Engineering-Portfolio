# project/

Everything specific to this project. The shared tools are in `../general/`.

| Folder | Holds |
|---|---|
| `brief/` | the task sheet, rubric, page plan, sources |
| `assets/photos/raw/` | your original photos (never edited) |
| `assets/photos/ready/` | upright, resized copies made by `general/tools/photo_prep.py` |
| `assets/cad/`, `assets/screenshots/`, `assets/sketches/` | CAD exports (Onshape tool writes here), screenshots, scanned sketches |
| `logs/` | DECISIONS, BUILD_LOG, TESTS, PREFERENCES (append only) |
| `outputs/<deliverable>/` | build script, versioned decks and PDFs, VERSIONS.md |
| `outputs/reviews/` | marking-loop and review notes |
| `outputs/renders/` | PNG renders and contact sheets (not in git) |
| `src/` | the project's own code, if any |
| `design.json` | optional colour overrides for the design system |
