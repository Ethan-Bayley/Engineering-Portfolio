# Research prior work

1. Read `project/PROJECT.md` for the problem and the goal.
2. Search (WebSearch, standard mode first). Prefer primary sources: papers (open access), datasheets, official docs.
3. For each source record in `project/brief/SOURCES.md`: title, authors, year, link, licence of any figure used, what it
   does, and where it falls short compared with this project. Quote under 15 words; summarise the rest.
4. Build a comparison table (approach, needs, output, limits) with this project as the last row.
5. Figures from papers only with a compatible licence, credited on the page and in `project/assets/CREDITS.md`.
6. Log the decision the research led to in `project/logs/DECISIONS.md`.
